                  PS4 (shadPS4)

                  Play the PS4 version of Happy Dungeons in the shadPS4 emulator as this same player: same character, saves and friends. It signs in with its own login on this server, never with your public shadNet password.

                  Account ID Password

                  NOT the password of your public shadNet account or of anything else.

                  In shadPS4: Settings > Manage Users > Create User, pick it, click ShadNet..., tick Enable ShadNet for this user and enter the Account ID and password. Click Set Default User on it before you play Happy Dungeons. Patches and the rest of the setup: PS4 setup page.
